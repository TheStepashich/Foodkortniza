# Сайт Фудкортницы

Одностраничник для GitHub Pages (ветка `gh-pages`). Полностью автономный: без внешних шрифтов, библиотек и картинок — всё лежит в этой папке.

## Открыть локально

```bash
python3 -m http.server 8080
# http://localhost:8080
```

Можно просто открыть `index.html` в браузере — всё работает и без сервера.

## Структура

- `index.html` — разметка страницы;
- `styles.css` — стили, адаптив и тёмная тема по системной настройке;
- `script.js` — появление блоков при скролле и интерактивный макет приложения;
- `assets/logo.svg` — копия логотипа «Картошка фри»;
- `downloads/foodkortniza.apk` — оптимизированная release-сборка;
- `stores.json` — каталог магазинов, который скачивает приложение: `https://foodkortniza.potatom.net/stores.json`;
- `.nojekyll` — чтобы GitHub Pages не игнорировал файлы, начинающиеся с точки.

## Обновить APK

Соберите `:app:assembleRelease` в ветке `main`, вернитесь сюда и положите файл в `downloads/`:

```bash
./update-apk.sh /путь/к/app-release.apk
```

Ссылки на APK в шапке, секции скачивания и подвале используют один и тот же путь. При желании замените его на CDN или ссылку на магазин.

При добавлении магазина обновите `stores.json` и здесь, и в `app/src/main/assets/stores.json` ветки `main` — вторая копия нужна приложению, если сеть недоступна.
